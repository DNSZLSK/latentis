The Company

A department for the time in between.

Every day, millions of capable people wait while a machine thinks on their behalf. Latentis was founded on the belief that this time should not be wasted. It should be refined.

Our Refiners work on the Context Floor, a quiet space beside the conversation. They find tokens that behave improperly and return them to where they belong. The machine does not notice. The Refiner does.

Latentis does not measure productivity. It measures diligence, which is the same thing, but warmer.

Latent Data Refinement

Four departments. One floor.

Most numbers on the floor are calm. Some are suspect: they glow, and the way they behave tells a trained Refiner where they belong. Training takes about a minute.

Disclosures

What Latentis touches.

Latentis runs as function hooks inside Claude Code. We encourage every Refiner to read register.tsx and board.tsx before installing this or any mod. They are short.

  • It reads exactly one file: .git/HEAD in the working directory, to name your file after your branch. A worktree, a link or a detached HEAD reads as detached.
  • No processes, no network, no tool hooks. It never sees or changes what your agent runs.
  • Your progress is kept in its own plugin store, a JSON file under your Claude Code configuration directory.
  • Source, issues and licence (MIT): github.com/DNSZLSK/latentis.
